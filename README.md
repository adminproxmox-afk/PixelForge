# PixelForge

PixelForge — пиксельный редактор на HolyC для TempleOS V5.03. Проект состоит из исходника [PixelForge.HC](PixelForge.HC) и этого README. Сторонние библиотеки не нужны.

## Самый простой запуск: TempleOS-Web

Этот способ не требует настраивать виртуальный диск и переносить файл в уже установленную виртуальную машину.

1. Скачайте `PixelForge.HC` на компьютер.
2. Откройте [TempleOS-Web](https://templeosweb.netlify.app/).
3. Откройте окно **Files** в интерфейсе сайта и перейдите в `C:/Home`.
4. Перетащите `PixelForge.HC` с компьютера в окно **Files**. Файл должен появиться в `C:/Home`.
5. Щёлкните по экрану TempleOS, чтобы направить туда клавиатуру, затем в командной строке введите:

   ```text
   #include "C:/Home/PixelForge.HC"
   ```

6. Нажмите Enter. Escape закрывает редактор; если есть несохранённые изменения, подтвердите выход.

TempleOS-Web запускает среду с ядром и компилятором TempleOS V5.03. Файлы `C:` сохраняются в данных браузера, поэтому для резервной копии используйте **Disk & Save → Export disk**. Описание окон **Files**, **HolyC Editor** и **Disk & Save** есть в [руководстве TempleOS-Web](https://github.com/ParkerrDev/TempleOS-Web/blob/master/Doc/Guide.md).

## Запуск в установленной TempleOS или виртуальной машине

Путь Windows вроде `C:\Users\...\PixelForge.HC` внутри TempleOS недоступен. Сначала перенесите файл в гостевую файловую систему. Например, подключите к виртуальной машине отдельный диск с разделом FAT32, скопируйте на него исходник в Windows, затем подключите диск к VM и смонтируйте его в TempleOS командой `Mount;`. Назначьте ему свободную букву, например `D:`. TempleOS поддерживает FAT32; для разделённого диска системная команда `Mount` назначает букву и монтирует разделы.

После монтирования скопируйте файл в домашний каталог TempleOS (замените `D:` на назначенную букву):

```text
Copy("D:/PixelForge.HC", "C:/Home");
```

Затем запустите программу той же командой:

```text
#include "C:/Home/PixelForge.HC"
```

Справка TempleOS описывает `Mount` для подключения диска и `F5` в File Manager для выполнения `#include` выбранного файла: [установка и Mount](https://www.templeos.info/Wb/Doc/Install.DD.HTML), [File Manager](https://templeos.info/Wb/Doc/FileMgr.DD.HTML).

## Управление редактором

### Мышь

- Щёлкните по инструменту слева, затем рисуйте на полотне левой кнопкой мыши. Pencil, Eraser и Spray рисуют при перетаскивании.
- Для Line, Rect и Circle нажмите левую кнопку, переместите мышь, чтобы увидеть контур, и отпустите кнопку для применения фигуры.
- Левая кнопка по цвету выбирает основной цвет. Правая кнопка по цвету выбирает фоновый цвет.
- Правая кнопка и перетаскивание по полотну перемещают рабочую область.
- Кнопки справа меняют цвета местами, форму и размер кисти, радиус Spray, сетку, заполнение фигур и масштаб.

### Кнопки

- **New** — запросить ширину и высоту (от 1 до 256 пикселей).
- **Open** — открыть `.pfg` по полному пути TempleOS.
- **Save** — сохранить по последнему использованному пути; при первом сохранении запрашивается путь.
- **Save As** — сохранить в путь, введённый пользователем.
- **Undo / Redo** — отменить или вернуть действие. Хранятся последние восемь снимков.
- **Clear** — очистить холст фоновым цветом.
- **Fill** — залить весь холст основным цветом.
- **Export GR** — экспортировать нативный сжатый файл `.GR.Z`; расширение добавляется автоматически, если не задано.

Для файлов вводите полный путь, например `C:/Home/sprite.pfg`.

### Клавиатура

| Клавиша | Действие |
| --- | --- |
| `1`–`8` | выбрать Pencil, Eraser, Line, Rect, Circle, Bucket, Eyedropper, Spray |
| `Z` / `Y` | Undo / Redo |
| `S` | Save |
| `O` | Open |
| `N` | New |
| `G` | показать или скрыть сетку |
| `F` | переключить заполнение Rect/Circle |
| `H` / `J` / `K` / `L` | переместить полотно влево / вниз / вверх / вправо |
| `Escape` | выйти; при несохранённых изменениях появится подтверждение |

## Работа с изображениями

- Холст создаётся заданного размера до 256×256; по умолчанию начальный холст — 64×64.
- Палитра содержит 16 цветов TempleOS. Основной цвет используется для рисования и заливки, фоновый — для ластика и очистки.
- Доступны Pencil, Eraser, Line, контурный или заполненный Rectangle/Circle, Bucket, Eyedropper и Spray.
- Кисть бывает квадратной или круглой, размером 1–16 пикселей. Для Spray отдельно настраивается радиус.
- Масштаб — от 1× до 8×. Сетка отображается при масштабе 4× и выше.
- При изменении изображения в заголовке появляется `*`. New, Open и выход спрашивают подтверждение перед удалением несохранённых изменений.

## Формат `.pfg`

Версия 1 хранит заголовок и пиксели последовательно: четыре байта `PFG1`, версия `U16`, ширина `U16`, высота `U16`, 16 байтов таблицы цветов 0–15, затем `width × height` байтов пикселей в порядке строк. Числовые поля записаны в little-endian, как в TempleOS x86-64. Для номера цвета используются младшие четыре бита байта пикселя.

При открытии проверяются магическое число, версия, размеры, таблица цветов и точная длина файла. При сохранении редактор сообщает об успехе только после полной записи файла.

## Ограничения и проверка

- Максимум изображения — 256×256; история содержит до восьми снимков.
- Верхние надписи File/Edit/Image/View/Help — заголовки; действия выполняются кнопками и горячими клавишами выше.
- При масштабе выше 1× пиксели полотна рисуются отдельно, а интерфейс перерисовывается после событий.
- Исходник использует системные API TempleOS V5.03. В рабочей среде, где был подготовлен проект, не было виртуальной машины/компилятора TempleOS, поэтому компиляция и запуск здесь не проверялись. Если при первом запуске появится сообщение компилятора, сохраните его целиком: по нему можно исправить несовместимое место.
